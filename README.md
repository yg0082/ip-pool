# 优选IP集合

一个安卓 App：把「优选IP集合」空间装进口袋。聚合器每 4 小时收集的 Cloudflare 优选 IP 池，随时查看、复制、下载；官方 Cloudflare IP 段随机抽取，想抽多少抽多少。

## 功能

- 两个标签页：「聚合优选IP」「Cloudflare 优选 IP」，一次只显示一个
- 聚合优选IP：
  - Gist 配置：第一次打开时粘贴一次聚合器 Gist 链接，存在本机，不上传、不进代码
  - 聚合订阅：显示 Clash 和 sing-box 两条订阅链接（由 Gist 派生），各带复制按钮；聚合器直接生成的节点，没在手机上测过
  - 优选 IP 池：按地区分组（香港、新加坡、日本、美国、台湾、韩国）+ 全部，每组显示条数、复制、下载；全部组另有固定高度的可滚动 IP 显示框；顶部「每 4 小时自动收集一次」+ 刷新按钮
- Cloudflare 优选 IP：
  - 200 / 500 / 1000 / 1500 四档，每按一次从官方 15 个 IPv4 段（约 152 万地址）重新随机抽取
  - 每组显示条数、复制、下载；页面上不展示 IP 列表

## 使用方法

1. 打开 App，先在「聚合优选IP」页的 Gist 配置里粘贴聚合器 Gist 链接，点保存（只存本机）。
2. 点刷新，拉取最新的优选 IP 池。
3. 哪个地区的 IP 想用，点复制或下载，粘贴到批量测IP 里测，或直接用。
4. Cloudflare 页按需点 200 / 500 / 1000 / 1500 抽取，复制或下载。

## 隐私说明

- App 不注册、不登录、不收集你的个人信息。
- Gist 链接、订阅链接只保存在本机；公开仓库里只有工具本身，没有你的订阅地址和凭证。
- IP 池从 Gist 拉取，Cloudflare 随机抽取完全在本地算，不联网。

## 下载安装

- 推荐：打开本仓库的 Releases 页，下载最新版 APK，手机上点开安装（需允许“安装未知应用”）。
- 备用：打开本仓库的 Actions 页，找最新一次 Build APK，在 Artifacts 里下载 `app-debug-apk`，解压得到 APK 再安装。

## 自己编译

- 用 Android Studio 打开本仓库，点 Run 即可；或
- 把代码推到自己 fork 的仓库，GitHub Actions 会自动跑 `gradle assembleDebug` 编译出 APK。
